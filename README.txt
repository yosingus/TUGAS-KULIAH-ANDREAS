File: index.html (menu + iframe), beranda.html, penggajian.html (form 7 isian), data-gaji.html (tabel rowspan), tentang.html.

Cara menjalankan: ekstrak ZIP, buka index.html di browser. Klik menu kiri untuk mengganti konten iframe.

Hosting Vercel:
1. Ekstrak ZIP.
2. Upload folder ini ke repository GitHub.
3. Di Vercel pilih Add New > Project, lalu import repository GitHub.
4. Framework Preset: Other. Build Command dan Output Directory kosongkan.
5. Klik Deploy.

Sebelum dikumpulkan, ganti [Isi nama lengkap abang] di tentang.html.
Form hanya simulasi dan tidak menyimpan data. Data tabel fiktif.
Website memakai iframe HTML5 sesuai materi, bukan frameset lama.
